# Clear listing status badges

## What will change
- Use one plain-language label set everywhere: **Vacant**, **Living Here Now**, and **Available Soon**.
- Show the label directly on every map price pin so tenants can read the status without opening it.
- Match the same labels on property cards, details, filters, and accessible map descriptions.
- Keep the existing colors and availability-date details so no listing information is lost.

## Technical details
- Centralize the short status label in the listing data helper.
- Update map marker text and popup information without changing map behavior.
- Reuse the helper in cards, details, and filters to prevent inconsistent wording.
- Verify the app build and map rendering after the change.
